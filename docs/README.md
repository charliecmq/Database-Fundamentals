# Documentation

This folder holds the written documentation for the E-Bookstore Database System.

Suggested files:

- `assignment-brief.pdf` — the original coursework question/brief.
- `report.pdf` — the full project report (introduction, advantages of databases/DBMS, business rules, ER diagram, database diagram, and SQL screenshots).

> Tip: convert any Word (`.docx`) documents to PDF before uploading, so they preview directly on GitHub.
